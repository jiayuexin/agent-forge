# Dashboard 黑客终端风格改版计划

## 概览

### 目标

将现有dashboard从默认Ant Design后台风格改版为**极简终端黑客风格**，打造机智、有吸引力的视觉效果，符合AgentForge作为AI Agent开发平台的技术气质。

### 设计方向定位

| 设计元素       | 方案选择                                                                         |
| -------------- | -------------------------------------------------------------------------------- |
| **整体基调**   | 纯黑背景 + CRT荧光绿主色调 + 扫描线纹理                                          |
| **Typography** | 选用 `JetBrains Mono` 等宽编程字体 + 偶尔赛博朋克显示字体点缀                    |
| **色彩方案**   | 主色：`#00ff00` (CRT绿)，强调色：`#0088ff` (霓虹蓝)，背景：`#0a0a0a` → `#000000` |
| **动画效果**   | 字符闪烁动画、开机引导动画、数据流扫过效果、鼠标跟踪辉光                         |
| **布局**       | 保留现有结构，但用赛博边框、发光分隔线重构视觉层次                               |

### 当前状态分析

- **技术栈**：React 18 + TypeScript + Vite + Tailwind CSS + Ant Design
- **现有结构**：AppLayout → Sidebar + Header + Content 三栏布局
- **页面数量**：共12个页面（Home、ClientAgent列表/创建/详情、Node列表/详情/聊天、Capability列表/市场/详情/分发、Playground、Monitor）
- **依赖**：使用Ant Design组件库，Tailwind只做工具类使用，未自定义主题

### 设计原则

1. **功能优先**：视觉改版不改变现有业务逻辑和数据流向
2. **最小侵入**：尽量通过CSS变量和全局样式覆盖实现主题切换，不大量重写业务组件
3. **完整一致性**：全站所有页面统一风格，保持视觉一致性
4. **性能可控**：动画使用CSS优先，避免过度使用JS动画导致性能问题

## proposed Changes

### 1. 全局样式与主题配置

**文件**：

- `/packages/dashboard/src/index.css` - 新增CSS变量定义、全局黑客终端样式
- `/packages/dashboard/tailwind.config.ts` - 扩展自定义颜色、字体、动画

**内容**：

- 定义黑客终端主题的CSS变量（背景色、主色、辅助色、边框色）
- 引入JetBrains Mono字体（通过Google Fonts）
- 添加扫描线动画效果（伪元素实现）
- 添加字符闪烁keyframes
- 设置body背景为纯黑，文本为CRT绿色
- Tailwind配置扩展自定义颜色和字体族

### 2. 布局组件重构

**文件**：

- `/packages/dashboard/src/components/layout/AppLayout.tsx` - 添加背景纹理和扫描线效果
- `/packages/dashboard/src/components/layout/Sidebar.tsx` - 重构侧边栏为终端风格
- `/packages/dashboard/src/components/layout/Header.tsx` - 重构头部为终端风格

**内容**：

- **AppLayout**：添加扫描线全屏覆盖层，添加背景噪点纹理，整体CRT滤镜效果
- **Sidebar**：保留现有菜单结构，替换为终端风格样式，logo改为发光CRT效果，菜单项添加hover发光效果
- **Header**：改为暗绿色背景，添加终端提示符样式，移除白色背景

### 3. 首页重构设计

**文件**：

- `/packages/dashboard/src/pages/Home.tsx` - 完全重构首页视觉，保持原有数据逻辑

**内容**：

- 移除Ant Design Card组件，改用自定义终端窗口风格卡片
- 状态栏数据改为终端输出格式（类似`[INFO] Nodes: 3/2 online`）
- 添加开机引导字符逐字打印动画
- 近期事件改为终端日志格式，带时间戳和级别标签
- 快捷操作按钮改为绿色荧光边框按钮，hover发光效果

### 4. 通用组件样式覆盖

**文件**：

- 在 `index.css` 中添加Ant Design组件的样式覆盖规则

**内容**：

- 覆盖Ant Design默认变量：色、背景色、边框色
- 覆盖Card、Button、Menu、Input、Table等常用组件为终端风格
- 保持组件功能不变，只改视觉样式

### 5. 新增动态效果组件（可选增强）

**文件**：

- `/packages/dashboard/src/components/Hacker/CRTScanlines.tsx` - 扫描线全屏组件
- `/packages/dashboard/src/components/Hacker/Typewriter.tsx` - 打字机动画组件

**内容**：

- 可复用的扫描线效果组件，参数化控制透明度和速度
- 可复用的打字机效果组件，用于标题和欢迎文字

## Assumptions & Decisions

| 决策项             | 选择                              | 原因                                                           |
| ------------------ | --------------------------------- | -------------------------------------------------------------- |
| **保留Ant Design** | 是，通过CSS变量重主题化           | 避免大规模重写，保持现有表单、表格等复杂组件功能，只改视觉     |
| **字体选择**       | JetBrains Mono + 备用系统等宽字体 | JetBrains Mono是现代编程字体，开源免费，字符清晰，适合终端风格 |
| **色彩方案**       | 黑底CRT荧光绿 (#00ff00)           | 经典终端黑客风格，对比度高，可读性好，长时间使用不累眼         |
| **扫描线效果**     | CSS伪元素全屏覆盖                 | 不占用额外DOM层级，性能好，可以通过opacity控制强度             |
| **动画强度**       | 适度，只在关键位置使用            | 避免过度动画干扰实际使用，只在首页加载、hover状态添加效果      |
| **响应式**         | 保持现有Ant Design响应式          | 不改变布局结构，只改视觉样式                                   |

## Implementation Steps

1. 更新 `tailwind.config.ts` 添加自定义主题配置
2. 重写 `index.css` 定义全局CSS变量和黑客终端基础样式
3. 重构 `Sidebar.tsx` 侧边栏样式
4. 重构 `Header.tsx` 头部样式
5. 更新 `AppLayout.tsx` 添加扫描线和背景效果
6. 完全重构 `Home.tsx` 首页视觉效果
7. 添加CSS规则覆盖Ant Design默认组件样式
8. 验证所有页面显示效果，调整细节

---

## Verification Steps

1. **构建验证**：运行 `pnpm build` 确保无编译错误
2. **类型检查**：运行 `pnpm type-check` 确保无类型错误
3. **启动开发服务器**：运行 `pnpm dev` 检查视觉效果
4. **页面检查清单**：
   - [ ] 首页：打字动画正常，数据卡片显示正确
   - [ ] 侧边栏：菜单hover发光效果正常
   - [ ] 所有页面：背景黑色、文字绿色，扫描线效果可见
   - [ ] 按钮、卡片、表单：样式适配主题，功能正常
   - [ ] 响应式：折叠侧边栏正常，不同屏幕尺寸布局正确
5. **性能检查**：页面滚动流畅，动画无掉帧

## Risk Assessment

| 风险                     | 影响                 | 应对措施                                                 |
| ------------------------ | -------------------- | -------------------------------------------------------- |
| Ant Design样式覆盖不完全 | 部分组件仍显示原主题 | 使用!important确保覆盖，逐个组件测试调整                 |
| 扫描线动画影响性能       | 页面可能卡顿         | 使用CSS will-change优化，提供opacity参数可调             |
| 对比度不够影响可读性     | 用户体验下降         | 主文本使用较亮的绿色，次要文本使用暗绿色，保持足够对比度 |

## Expected Outcome

改版完成后，dashboard将呈现出：

- ✅ 纯黑背景 + 荧光绿色字符的经典终端黑客视觉
- ✅ 细腻的扫描线纹理效果，模拟老CRT显示器质感
- ✅ 首页开机引导打字机动画，营造启动终端的沉浸感
- ✅ 全站统一风格，按钮、卡片、菜单都适配终端主题
- ✅ 原有功能完全保留，只是视觉焕新
